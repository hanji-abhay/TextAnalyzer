# TextAnalyzer 📝

A Python-based Text Analyzer built using Object-Oriented Programming (OOP) concepts.  
This project analyzes a given text to extract useful insights such as word frequency, character frequency, palindromes, and vowel/consonant counts.

---

## 🚀 Features

- 📊 Word frequency analysis
- 🔤 Character frequency analysis (alphabets only)
- ⭐ Most frequent and least frequent words
- 🔁 Palindrome word detection
- 🔠 Vowel and consonant counting
- 🧱 Clean OOP-based class structure

---

## 🛠️ Technologies Used

- Python 3
- Core Python concepts:
  - Dictionaries
  - Loops & conditionals
  - Functions
  - Object-Oriented Programming (OOP)
